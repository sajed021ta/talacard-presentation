# استودیوی ارائهٔ طلاکارت

نسخهٔ مستقل آرتیفکت طلاکارت، همراه با ویرایشگر فارسی و دو پروژهٔ آماده:

- **دیزاین اپ:** همان ۶ بخش و ۱۴ قدم نسخهٔ اصلی، با فریم‌ها و انیمیشن‌های موجود.
- **پیشنهاد همکاری:** ۱۲ صفحه بر اساس PDF، با ۹ ویدیوی انتخاب‌شده و تصویر صفحات بدون فیلم.

## اجرا

[Node.js نسخهٔ ۲۲ یا جدیدتر](https://nodejs.org/) کافی است. نصب کتابخانه لازم نیست.

```sh
git clone https://github.com/sajed021ta/talacard-presentation.git
cd talacard-presentation
node server.mjs
```

ویرایشگر: http://127.0.0.1:4177/#edit

نمایش ارائه: http://127.0.0.1:4177/

نسخهٔ استخراج‌شدهٔ اصلی: http://127.0.0.1:4177/original/index.html

پورت دیگر: `TALACARD_PORT=4180 node server.mjs`.

## ویرایش هر صفحه

۱. پروژه را از منوی بالای صفحه انتخاب کن.

۲. از فهرست سمت راست یک صفحه را انتخاب کن.

۳. در **محتوا**، نام، عنوان، عبارت طلایی، توضیحات و قالب را تغییر بده.

۴. در **رسانه**، عکس یا ویدیو را از کتابخانه انتخاب کن یا فایل جدید اضافه کن. نمایش کامل، برش، جای رسانه و کاور ویدیو قابل تنظیم‌اند. انتخاب رسانه روی یک صحنهٔ اپ، قالب آن صفحه را به «متن و رسانه کنار هم» تغییر می‌دهد؛ برای برگشت، «فلو اصلی اپ» را انتخاب کن.

۵. در **حرکت و ظاهر**، مدت صفحه، افکت ورود، شدت حرکت، اندازهٔ عنوان و رنگ‌ها را تنظیم کن. انیمیشن داخلی صحنه‌های اپ همان منطق اصلی است؛ افکت ورود انتخابی برای قالب‌های رسانه‌ای اعمال می‌شود.

۶. **ذخیرهٔ پروژه** را بزن. متن و تنظیمات در `content.json` و نسخهٔ پیش‌فرض وب در `public/default-content.json` ذخیره می‌شوند. فایل قبلی در `content.backup.json` باقی می‌ماند. فایل‌های جدید در `public/media` کپی می‌شوند؛ فایل اصلی دستگاه دست‌نخورده می‌ماند.

افزودن صفحه از علامت + کنار فهرست، و کپی، جابه‌جایی و حذف از پایین پنل انجام می‌شود. حذف صفحه رسانهٔ آن را از دیسک حذف نمی‌کند. برگرداندن و انجام دوباره در همین نشست فعال‌اند. پیش‌نویس ذخیره‌نشده، در صورت موجودبودن نسخهٔ پایهٔ یکسان، از مرورگر بازیابی می‌شود.

**متن داخل تصاویر اپ** بخشی از فریم‌های اصلی است و به‌صورت متن زنده استخراج نشده است. عنوان‌ها و توضیحات کنار آن‌ها قابل ویرایش‌اند. برای تغییر نوشتهٔ داخل فریم، تصویر اپ را جایگزین کن یا قالب صفحه را تغییر بده.

## دریافت و انتقال پروژه

از منوی سه‌نقطه، **دریافت فایل پروژه** و **بارگذاری فایل پروژه** در دسترس‌اند. JSON محتوا و مسیر رسانه‌ها را نگه می‌دارد؛ خود عکس‌ها و ویدیوها داخل JSON نیستند. برای انتقال کامل، کل پوشهٔ پروژه یا مخزن را با `public/media` و `original/assets` منتقل کن.

برای ساخت خروجی ایستای وب:

```sh
node scripts/export.mjs
```

پوشهٔ `dist` آمادهٔ میزبانی در ریشهٔ یک وب‌سایت است. نسخهٔ ایستا امکان ویرایش و ذخیره در همان مرورگر و دریافت JSON را دارد؛ ذخیره روی دیسک و افزودن رسانه به سرور محلی نیاز دارند. انتشار روی اینترنت در این پروژه انجام نشده است.

## ثبت تغییرات در گیت‌هاب

دکمهٔ ذخیره در پنل، فایل‌های **محلی** را ذخیره می‌کند. ارسال به گیت‌هاب با Git یا GitHub Desktop انجام می‌شود. توکن گیت‌هاب در مرورگر نگهداری نمی‌شود.

```sh
git add content.json public/default-content.json public/media
git commit -m "Update presentation content"
git push
```

اگر فقط متن را در گیت‌هاب تغییر می‌دهی، هر دو فایل `content.json` و `public/default-content.json` را یکسان نگه دار؛ اجرای پنل و ذخیرهٔ آن این کار را خودکار انجام می‌دهد.

## کلیدهای میان‌بر

| کلید | کار |
|---|---|
| فاصله | پخش / توقف |
| جهت چپ / راست | صفحهٔ بعد / قبل |
| Ctrl/⌘ S | ذخیره |
| Ctrl/⌘ Z | برگرداندن تغییر |
| Ctrl/⌘ Shift Z | انجام دوباره |
| Esc | خروج از تمام‌صفحه |

پخش به انتخاب کاربر شروع می‌شود. هنگام توقف، زمان‌بندی انیمیشن‌های اپ و ویدیوها هم متوقف می‌شود. برای حالت کاهش حرکت سیستم، افکت‌های تزئینی کنار گذاشته می‌شوند.

## ساختار

```text
content.json                 متن و تنظیمات همهٔ پروژه‌ها
public/index.html            پوستهٔ ویرایشگر و نمایشگر
public/studio.js              ویرایش، پخش، تاریخچه و ذخیره
public/studio.css             طراحی واکنش‌گرا
public/model.js               اعتبارسنجی مشترک
public/media/                 ویدیوها، تصاویر و رسانه‌های جدید
public/legacy/                اجرای قابل‌کنترل انیمیشن اصلی
original/source.html          بایگانی کامل کد کاربر با رسانه‌های درون‌فایلی
original/index.html           نسخهٔ مستقل استخراج‌شده
original/app.js               منطق اصلی با بارگذاری رسانه از فایل
original/style.css            طراحی اصلی
original/assets/              ۱۵ تصویر و ۵ فونت استخراج‌شده
references/proposal.pdf       مرجع پروپوزال
ASSETS.json                   منشأ رسانه‌ها
server.mjs                    سرور محلی ذخیره و آپلود
tests/                        تست اعتبارسنجی و ذخیره‌سازی
```

کد اختصاصی میزبان Claude که در سرآیند صفحه تزریق می‌شد جزو کد ارائه نیست و در نسخهٔ مستقل اجرا نمی‌شود. کد کاربر، داده‌های تصویری و فونت‌ها حفظ شده‌اند. فایل‌های اصلی کاربر و پوشهٔ synced `sources/` تغییر نکرده‌اند.

## بررسی

```sh
node --test tests/*.test.mjs
node --check public/studio.js
node --check public/legacy/app.js
```

سرور فقط روی `127.0.0.1` گوش می‌دهد و برای اینترنت یا چند کاربر هم‌زمان طراحی نشده است. ذخیرهٔ هم‌زمان از دو پنجره با شناسهٔ نسخه کنترل می‌شود؛ تغییر قدیمی بی‌صدا جای تغییر جدید را نمی‌گیرد.

رسانه‌ها برای حفظ کیفیت اصلی داخل مخزن هستند و دانلود اولیه نسبتاً حجیم است. حقوق استفاده از تصاویر، فیلم‌ها و فونت‌های استخراج‌شده همان حقوق فایل‌های منبع است؛ مجوز عمومی جدیدی برای آن‌ها صادر نشده است.
