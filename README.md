# استودیوی ارائهٔ طلاکارت

نسخهٔ مستقل آرتیفکت طلاکارت، همراه با ویرایشگر فارسی و چهار پروژهٔ آماده بر پایهٔ [مرجع به‌روز Claude](https://claude.ai/artifact/A1CLteSL9qqvEHSW4Rpa8r)، ثبت‌شده در ۲۰۲۶-۱۰-۱۹:

- **دیزاین اپ:** ۲۴ قدم مرجع به‌روز، به‌علاوهٔ صفحهٔ جزئیات شعبه از نسخهٔ قبلی؛ در مجموع ۲۵ صفحه.
- **پیشنهاد همکاری:** ۱۲ صفحه بر اساس PDF، با ۹ ویدیوی انتخاب‌شده و تصویر صفحات بدون فیلم.
- **طلاپرداز:** ۲۲ قدم خرید و تحویل از موجودی، با فریم‌ها و انیمیشن‌های مرجع.
- **تحویل از موجودی:** ۱۳ قدم تحویل طلای موجود در دیجی‌کالا از طلاپرداز.

نوشته‌ها، قالب‌بندی، رسانه‌ها و چیدمان‌های ویرایش‌شده حفظ می‌شوند. صفحهٔ جزئیات شعبه با نمایشگر نسخهٔ قبلی اجرا می‌شود. بایگانی اولیه در `original/` دست‌نخورده باقی مانده است.

## اجرا

[Node.js نسخهٔ ۲۲ یا جدیدتر](https://nodejs.org/) کافی است. نصب کتابخانه لازم نیست.

```sh
git clone https://github.com/sajed021ta/talacard-presentation.git
cd talacard-presentation
node server.mjs
```

ویرایشگر: http://127.0.0.1:4177/#edit

نمایش ارائه: http://127.0.0.1:4177/

نسخهٔ استخراج‌شدهٔ اصلی: http://127.0.0.1:4177/original/index.html

پورت دیگر: `TALACARD_PORT=4180 node server.mjs`.

## ویرایش هر صفحه

۱. پروژه را از منوی بالای صفحه انتخاب کن.

۲. از منوی سمت راست یک بخش را انتخاب کن، سپس از ردیف بالای ارائه صفحهٔ دلخواه را بزن.

برای افزودن زیرصفحه به هر بخش، همان بخش را انتخاب کن و از ردیف بالا **افزودن زیرصفحه** را بزن. صفحه در پایان زیرصفحه‌های همان بخش اضافه می‌شود؛ نامش را در «نام در فهرست صفحه‌ها» تغییر بده و متن و رسانه‌اش را جدا ویرایش کن. ذخیره و همگام‌سازی خودکار است.

۳. در **محتوا**، نام، عنوان، عبارت طلایی، توضیحات و قالب را تغییر بده. توضیحات در باکس‌های مستقل و قابل افزودن، حذف و جابه‌جایی هستند. «جمله‌ها را به باکس‌های جدا تبدیل کن» یک پاراگراف را تفکیک می‌کند. برای حرکت آزاد روی صفحه، «جابه‌جایی» همان باکس را بزن و دستگیره‌اش را بکش.

نوار قالب‌بندی متن برای عنوان و باکس فعال مشترک است: فونت، اندازه، رنگ، ضخیم، مورب، زیرخط، چپ‌چین، راست‌چین، وسط‌چین، تراز دوطرفه و فاصلهٔ خطوط. با انتخاب چند کلمه، قالب فقط روی همان بخش اعمال می‌شود؛ بدون انتخاب، کل باکس تغییر می‌کند. Ctrl/⌘ B، I، U و برگرداندن/انجام دوباره داخل هر باکس فعال‌اند.

۴. در **رسانه**، عکس یا ویدیو را از کتابخانه انتخاب کن یا فایل جدید اضافه کن. نمایش کامل، برش، جای رسانه و کاور ویدیو قابل تنظیم‌اند. انتخاب رسانه روی یک صحنهٔ اپ، قالب آن صفحه را به «متن و رسانه کنار هم» تغییر می‌دهد؛ برای برگشت، «فلو اصلی اپ» را انتخاب کن.

در همین تب، **افکت رسانه** شامل زوم داخل/بیرون/رفت‌وبرگشت، حرکت در چهار جهت، آشکار شدن آرام و از محو به واضح است. مدت افکت (۰٫۲ تا ۱۲۰ ثانیه)، تأخیر شروع، شدت، شتاب و تکرار مستقل تنظیم می‌شوند. لوپ ویدیو و تکرار افکت دو تنظیم جدا هستند؛ پایان افکت صفحه را عوض نمی‌کند. «بازپخش افکت» نتیجه را دوباره نشان می‌دهد.

۵. در **حرکت و ظاهر**، از **پس‌زمینه و نمایش رسانه** یکی از گزینه‌های «همراه با مرجع · خطوط طلایی متحرک» یا «ساده · رنگ انتخابی» را انتخاب کن. خطوط طلایی همان پس‌زمینهٔ متحرک مرجع هستند و روی صفحه‌های ویدیویی هم نمایش داده می‌شوند. مدت صفحه، افکت ورود، شدت حرکت، اندازهٔ عنوان و رنگ‌ها نیز در همین تب قابل تنظیم‌اند. انیمیشن داخلی صحنه‌های مرجع حفظ شده است؛ افکت ورود انتخابی برای قالب‌های رسانه‌ای اعمال می‌شود.

۶. تغییرات خودکار ذخیره می‌شوند؛ برای ارسال فوری می‌توانی **ذخیره و همگام‌سازی** را هم بزنی. متن و تنظیمات در `content.json` و نسخهٔ پیش‌فرض وب در `public/default-content.json` ذخیره می‌شوند. فایل قبلی در `content.backup.json` باقی می‌ماند. فایل‌های جدید در `public/media` کپی می‌شوند؛ فایل اصلی دستگاه دست‌نخورده می‌ماند.

افزودن صفحه از علامت + کنار فهرست، و کپی، جابه‌جایی و حذف از پایین پنل انجام می‌شود. حذف صفحه رسانهٔ آن را از دیسک حذف نمی‌کند. برگرداندن و انجام دوباره در همین نشست فعال‌اند. پیش‌نویس ذخیره‌نشده، در صورت موجودبودن نسخهٔ پایهٔ یکسان، از مرورگر بازیابی می‌شود.

**متن داخل تصاویر اپ** بخشی از فریم‌های اصلی است و به‌صورت متن زنده استخراج نشده است. عنوان‌ها و توضیحات کنار آن‌ها قابل ویرایش‌اند. برای تغییر نوشتهٔ داخل فریم، تصویر اپ را جایگزین کن یا قالب صفحه را تغییر بده.

## دریافت و انتقال پروژه

از منوی سه‌نقطه، **دریافت فایل پروژه** و **بارگذاری فایل پروژه** در دسترس‌اند. JSON محتوا و مسیر رسانه‌ها را نگه می‌دارد؛ خود عکس‌ها و ویدیوها داخل JSON نیستند. برای انتقال کامل، کل پوشهٔ پروژه یا مخزن را با `public/media` و `original/assets` منتقل کن.

### مدل ویرایش یکپارچه

`public/editor-model.js` یک مدل پایدار و نسخه‌دار برای ویرایش تعریف می‌کند. `project.editor.surfaces` شامل یک سطح برای صفحهٔ اصلی و یک سطح برای هر صفحهٔ ارائه است. هر سطح مجموعه‌ای از المان‌های مستقل با `id`، `type`، `position`، `dimensions`، `zIndex`، `content`، `style` و `animation` دارد.

رندر فعلی همچنان از فیلدهای تثبیت‌شدهٔ صحنه استفاده می‌کند. پل `syncProjectEditor` آن فیلدها را با مدل المان‌ها همگام می‌کند و `updateEditorElement` تغییر یک المان را به ساختار فعلی برمی‌گرداند. این طراحی ظاهر، چیدمان و انیمیشن‌های فعلی را حفظ می‌کند و اجازه می‌دهد پنل‌های ویرایش بعدی بدون مهاجرت دوبارهٔ محتوا ساخته شوند. حالت ویرایش در `/#edit` و حالت نمایش در `/viewer.html` جدا هستند؛ هر دو یک فایل محتوای ذخیره‌شده را می‌خوانند.

برای ساخت خروجی ایستای وب:

```sh
node scripts/export.mjs
```

پوشهٔ `dist` آمادهٔ میزبانی در ریشهٔ یک وب‌سایت است. نسخهٔ ایستا امکان ویرایش و ذخیره در همان مرورگر و دریافت JSON را دارد؛ ذخیره روی دیسک و افزودن رسانه به سرور محلی نیاز دارند. نسخهٔ زندهٔ آنلاین از مسیر جداگانهٔ Worker و R2 استفاده می‌کند؛ این خروجی صرفاً نسخهٔ ایستای مستقل است.

## ثبت تغییرات در گیت‌هاب

ذخیرهٔ خودکار، فایل‌های **محلی** را ثبت و به لینک عمومی همگام می‌کند. ارسال سورس به گیت‌هاب با Git یا GitHub Desktop انجام می‌شود. توکن گیت‌هاب در مرورگر نگهداری نمی‌شود.

```sh
git add content.json public/default-content.json public/media
git commit -m "Update presentation content"
git push
```

اگر فقط متن را در گیت‌هاب تغییر می‌دهی، هر دو فایل `content.json` و `public/default-content.json` را یکسان نگه دار؛ اجرای پنل و ذخیرهٔ آن این کار را خودکار انجام می‌دهد.

## کلیدهای میان‌بر

| کلید | کار |
|---|---|
| فاصله | پخش / توقف |
| جهت چپ / راست | صفحهٔ بعد / قبل |
| Ctrl/⌘ S | ذخیره |
| Ctrl/⌘ Z | برگرداندن تغییر |
| Ctrl/⌘ Shift Z | انجام دوباره |
| Esc | خروج از تمام‌صفحه |

ویدیوهای هر صفحه بی‌صدا خودکار پخش می‌شوند. رفتن به صفحهٔ بعد یا قبل دستی است؛ پایان ویدیو، افکت یا مدت صفحه باعث تغییر صفحه نمی‌شود. پخش و توقف مشترک، زمان‌بندی انیمیشن‌های مرجع، خطوط طلایی، افکت رسانه و ویدیوها را هماهنگ کنترل می‌کند. زمان داخلی نمایشگر مرجع فقط با فرمان پخش‌کنندهٔ اصلی جلو می‌رود. برای حالت کاهش حرکت سیستم، افکت‌های تزئینی کنار گذاشته می‌شوند.

کد اختصاصی میزبان Claude که در سرآیند صفحه تزریق می‌شد جزو کد ارائه نیست و در نسخهٔ مستقل اجرا نمی‌شود. کد کاربر، داده‌های تصویری و فونت‌ها حفظ شده‌اند. فایل‌های اصلی کاربر و پوشهٔ synced `sources/` تغییر نکرده‌اند.

ادغام مرجع، متن‌های بدون تغییر را با مقایسهٔ نسخهٔ قبلی، نسخهٔ ویرایش‌شده و مرجع جدید به‌روز می‌کند؛ متن و قالب‌بندی ویرایش‌شده، رسانه‌ها، چیدمان دسکتاپ و موبایل و صفحه‌های سفارشی حفظ می‌شوند. اجرای دوباره، صفحهٔ تکراری نمی‌سازد و ویرایش‌های بعدی را جایگزین نمی‌کند. برای تهیهٔ نسخهٔ ادغام‌شده جهت بررسی، بدون تغییر فایل ورودی:

```sh
node scripts/merge-reference.mjs content.json > merged-content.json
```

## بررسی

```sh
node --test tests/*.test.mjs
node --check public/studio.js
node --check public/legacy/app.js
```

سرور فقط روی `127.0.0.1` گوش می‌دهد و برای اینترنت یا چند کاربر هم‌زمان طراحی نشده است. ذخیرهٔ هم‌زمان از دو پنجره با شناسهٔ نسخه کنترل می‌شود؛ تغییر قدیمی بی‌صدا جای تغییر جدید را نمی‌گیرد.

رسانه‌ها برای حفظ کیفیت اصلی داخل مخزن هستند و دانلود اولیه نسبتاً حجیم است. حقوق استفاده از تصاویر، فیلم‌ها و فونت‌های استخراج‌شده همان حقوق فایل‌های منبع است؛ مجوز عمومی جدیدی برای آن‌ها صادر نشده است.

## چیدمان و پخش جدید

دسته‌ها در سمت راست و زیرصفحه‌های دستهٔ فعال در بالای ارائه‌اند. صفحهٔ فعال با زمینهٔ تیره مشخص است. فلو پایین و تایم‌لاین حذف شده‌اند. همهٔ ویدیوها بی‌صدا خودکار پخش می‌شوند؛ تغییر صفحه با دکمهٔ بعدی/قبلی یا منو است. گزینهٔ «تکرار ویدیو» لوپ هر صفحه را تنظیم می‌کند.

در حالت ویرایش، دستگیرهٔ «جابه‌جایی متن» یا «جابه‌جایی رسانه» را بکشید؛ گوشهٔ پایین راست قاب، اندازه را تغییر می‌دهد. کلیدهای جهت روی دستگیره جابه‌جا می‌کنند و Shift + جهت اندازه را تغییر می‌دهد. چیدمان دسکتاپ و موبایل مستقل ذخیره می‌شود. «بازنشانی چیدمان این صفحه» قاب‌های سفارشی همان صفحه را پاک می‌کند؛ با Undo قابل بازگردانی است. ثبت تغییرات خودکار است؛ دکمهٔ «ذخیره و همگام‌سازی» ارسال فوری را هم فراهم می‌کند. نوشته‌های داخل تصاویر اصلی اپ همچنان بخشی از عکس‌اند.

## ذخیره و انتشار خودکار

دیگر برای تغییر محتوا درخواست انتشار لازم نیست. پس از حدود یک ثانیه مکث در ویرایشگر محلی، تغییر روی دستگاه ذخیره و به همان لینک عمومی ارسال می‌شود. نوار بالا دو وضعیت را جدا نشان می‌دهد. ارسال ویدیو به حجم و سرعت اینترنت وابسته است؛ هنگام قطع اینترنت نسخهٔ محلی حفظ و ارسال دوباره انجام می‌شود. سرور محلی باید در حال اجرا بماند. کلید انتشار فقط در پوشهٔ خصوصی دستگاه و متغیر محرمانهٔ سایت است؛ وارد مرورگر یا گیت نمی‌شود. محتوای زنده در R2 ذخیره می‌شود و برای هر تغییر محتوا commit گیت‌هاب ایجاد نمی‌شود. تغییر سورس برنامه همچنان نیاز به انتشار نسخهٔ برنامه دارد. راهنمای فنی: cloud/README.md.

### تغییرات ویرایشگر — ۲۰ اکتبر ۲۰۲۶

- برای رنگ بخشی از متن، کلمه یا جمله را با موس انتخاب و از رنگ‌های آماده یا انتخابگر رنگ استفاده کنید؛ نوار ابزار محدودهٔ انتخاب را نشان می‌دهد.
- در «رسانه»، «افزودن عکس یا ویدیو به این صفحه» را بزنید؛ چند فایل را نیز می‌توان یکجا انتخاب کرد. رسانهٔ اصلی حفظ می‌شود و تا ۱۲ قاب اضافه با جابه‌جایی، اندازه، لوپ و افکت مستقل دارید. برای کتابخانه، حالت «افزودن به‌عنوان رسانهٔ جدید» را انتخاب کنید.
- در «محتوا»، «نام بخش برای همهٔ زیرصفحه‌ها» را تغییر و «تغییر نام بخش» را بزنید. فیلد «انتقال این صفحه به بخش» فقط صفحهٔ فعلی را جابه‌جا می‌کند.
- در «حرکت و ظاهر»، دکمهٔ اعمال پس‌زمینه به همهٔ صفحه‌ها برای یکسان‌سازی همهٔ پروژه‌هاست.
- نسخهٔ مرجع ۲۰ اکتبر شامل تصاویر و موشن‌های تازهٔ خرید/فروش و انتخاب کارتِ آمادهٔ تحویل است. صفحه‌های حذف‌شده از مرجع و ویرایش‌های مالک حفظ می‌شوند.

تمام این تغییرات از مسیر ذخیره و همگام‌سازی خودکار فعلی استفاده می‌کنند.

### ذخیرهٔ هم‌زمان پنجره‌ها

تغییرات مستقل در دو پنجره یا بین پنجره و به‌روزرسانی پروژه، با مقایسهٔ نسخهٔ مبنا خودکار ادغام و دوباره ذخیره می‌شوند. اگر همان فیلد در دو نسخه تغییر کند، نسخهٔ پیش‌نویس حفظ و تعارض اعلام می‌شود؛ نسخه‌ای خودسرانه جایگزین دیگری نمی‌شود. پیش‌نویس مرورگر نسخهٔ مبنا را نیز نگه می‌دارد تا بعد از تازه‌سازی قابل بازیابی باشد.

### فهرست بولت‌دار

در محتوا، باکس متن را انتخاب و «فهرست بولت‌دار» را روشن کنید. هر خط یک مورد است؛ Enter مورد بعدی می‌سازد. کلیک دوباره فهرست را به متن معمولی برمی‌گرداند. رنگ کلمه‌ها، فونت، چینش و جابه‌جایی باکس حفظ می‌شوند و قالب فهرست نیز خودکار ذخیره می‌شود.

### صفحهٔ اول ارائه

آدرس اصلی صفحهٔ انتخاب چهار بخش را نشان می‌دهد: طلاپرداز، اپ طلاکارت، کارت طلا (مسیر تحویل از موجودی) و طلاکارت (پیشنهاد همکاری). هر کارت وارد بخش مربوط می‌شود. «صفحهٔ اول» و دکمهٔ بازگشت مرورگر منوی انتخاب را برمی‌گردانند. لینک‌های مستقیم `?deck=app`، `?deck=kiosk`، `?deck=deliv` و `?deck=proposal` نیز فعال‌اند. آدرس `/#edit` مستقیم پنل ویرایش را باز می‌کند.
