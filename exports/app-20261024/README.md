# App video exports

Six chapter MP4s are available directly in this folder. The complete movie is stored as two lossless binary parts. Download links for every movie are in [DOWNLOADS.md](DOWNLOADS.md).

To restore the complete MP4 on macOS/Linux:

```sh
cat talacard-app-complete-20261024.mp4.part1 talacard-app-complete-20261024.mp4.part2 > talacard-app-complete-20261024.mp4
```
